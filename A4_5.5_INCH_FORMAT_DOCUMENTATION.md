# 📄 Format Print A4 dengan Layout 5.5 Inci Per Halaman

## Overview

Fungsi `printSuratJalan` telah dikonfigurasi untuk mencetak dalam format **5.5 inci per halaman** pada kertas **A4**.

Setiap halaman adalah **dokumen lengkap** dengan Header, Items, Total, dan Footer sendiri.

---

## 📐 Spesifikasi Layout

### Ukuran Kertas

- **Paper Size**: A4 (210mm x 297mm / 8.27" x 11.69")
- **Orientasi**: Portrait

### Layout Per Halaman

- **Tinggi**: 5.5 inci
- **Lebar**: Full width A4
- **Padding**: 0.3in (vertical) x 0.4in (horizontal)

### Struktur Setiap Halaman

```
┌─────────────────────────┐
│ HEADER                  │
│ - Judul: SURAT JALAN   │
│ - No Halaman           │
│ - Info Dokumen         │
│ - Info Customer        │
├─────────────────────────┤
│ TABLE                   │
│ - Items (max 15)       │
│ - TOTAL Row            │
├─────────────────────────┤
│ FOOTER                  │
│ - Catatan              │
│ - Tanda Tangan         │
└─────────────────────────┘
  ↓ 5.5 inches
```

## 🎯 Cara Kerja

### Setiap Halaman Independen

Setiap halaman memiliki komponen lengkap:

- ✅ Header dengan informasi dokumen
- ✅ Tabel dengan items (max 15 items default)
- ✅ Total CARTON dan PACK
- ✅ Footer dengan catatan dan tanda tangan

## 💡 Keuntungan Format Ini

### ✅ **Setiap Halaman Berdiri Sendiri**

- Bisa dipotong dan didistribusikan terpisah
- Setiap halaman memiliki informasi lengkap
- Total keseluruhan ada di setiap halaman

### ✅ **Mudah Dipotong**

- Potong kertas A4 di 5.5" dari atas
- Setiap potongan adalah dokumen valid
- Cocok untuk distribusi ke multiple pihak

### ✅ **Hemat Kertas**

- 1 lembar A4 = 2 halaman dokumen (5.5" + 5.5" ≈ 11")
- Sisa space di A4 bisa untuk halaman berikutnya

### ✅ **Fleksibel**

- Bisa disesuaikan jumlah items per halaman
- Total selalu ditampilkan (grand total semua items)

## 📝 Detail Teknis

### Total Calculation

Total CARTON dan PACK adalah **grand total** dari semua items (tidak per halaman):

```javascript
const totalCarton =
  data.items?.reduce((sum, item) => sum + (item.carton_quantity || 0), 0) || 0;
const totalPack =
  data.items?.reduce((sum, item) => sum + (item.pack_quantity || 0), 0) || 0;
```

Jadi jika ada 50 items:

- Halaman 1 (items 1-15): Total = semua 50 items
- Halaman 2 (items 16-30): Total = semua 50 items
- Halaman 3 (items 31-45): Total = semua 50 items
- Halaman 4 (items 46-50): Total = semua 50 items

### Page Break

```css
.page-break {
  page-break-after: always;
  break-after: always;
}
```

Setiap halaman (kecuali yang terakhir) akan memiliki page break.

### Height Control

```css

  height: 5.5in;
  overflow: hidden;
  box-sizing: border-box;
}
```

## 🐛 Troubleshooting

### Problem: Konten terpotong

**Solusi**:

- Kurangi `itemsPerPage` dari 15 ke 12 atau 10
- Atau adjust height: `5.5in` → `5.8in`

### Problem: Total berbeda di setiap halaman

**Ini bukan bug!** Total adalah grand total dari semua items, bukan per halaman.

### Problem: Spacing tidak pas

**Solusi**:

- Adjust padding: `0.3in 0.4in`
- Adjust margin-bottom di header, table, footer

### Problem: Preview vs Print berbeda

**Solusi**:

- Pastikan Scale = 100%
- Pastikan Margin = None
- Enable Background Graphics
